# ⚠️ TECHNICAL DEBT & CODE HEALTH — YUMIGRAM

> **Политика нулевого скрытия проблем**: «Любой недостаток, недоработка или узкое место должны быть немедленно задокументированы и устранены по согласованному приоритету».

---

## 1. Текущий технический долг

### [TD-001] Отсутствие автоматических unit-тестов в Rust Core
* **Приоритет**: Высокий
* **Модули**: `core/src/db.rs`, `core/src/ghost.rs`, `core/src/agent.rs`
* **Проблема**: Компиляция проходит успешно (`cargo check`), но поведение SQLite транзакций, флагов Anti-Delete и работы Ghost-фильтра не покрыто тестами `cargo test`.
* **Решение**: Написать изолированные unit-тесты с in-memory SQLite базой данных (`:memory:`).

### [TD-002] Предупреждения Clippy в Rust Core
* **Приоритет**: Низкий (Code Polish)
* **Модули**: `core/Cargo.toml`, `core/src/models.rs`, `core/src/lib.rs`
* **Проблема**: 
  1. `#[derive(Default)]` можно вывести автоматически для `GhostConfig`.
  2. Предупреждение об неиспользуемой зависимости `android_logger` в `Cargo.toml`.
* **Решение**: Исправить атрибуты и активировать логгер при реальной инициализации через JNI.

### [TD-003] Настройка локального Gradle Wrapper для Android
* **Приоритет**: Высокий
* **Модули**: `android/`
* **Проблема**: Android-файлы созданы, но в каталоге `android/` еще не скопирован `gradlew` исполняемый скрипт и `local.properties` с путем к установленному на машине `ANDROID_HOME=/home/user/android-sdk`.
* **Решение**: Настроить `local.properties` и скопировать проверенный `gradle-wrapper.jar` для автономной сборки проекта через `./gradlew assembleDebug`.

### [TD-004] Передача данных через JSON-строки в JNI
* **Приоритет**: Средний
* **Модули**: `core/src/lib.rs`, `android/.../bridge/YumigramBridge.kt`
* **Проблема**: Сейчас списки чатов сериализуются в JSON-строку при передаче через JNI boundary. Для сотен чатов это может создавать накладные расходы по парсингу.
* **Решение**: На этапе оптимизации производительности перевести горячие пути передачи сообщений на прямой бинарный буфер (ByteBuffer / Direct Byte Buffer).
