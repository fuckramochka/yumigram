# 🎨 DESIGN SYSTEM SPECIFICATION — PIXEL MD3 EXPRESSIVE

> **Цель**: Создать ощущение системного флагманского приложения Google Pixel, превосходящего по эстетике и плавности стандартные Telegram-клиенты.

---

## 1. Цветовая модель: Dynamic Color (Monet)

Интерфейс Yumigram извлекает палитру из системных обоев пользователя через Material You API:

| Роль токена | Назначение в Yumigram | Поведение в Dark / Light |
| :--- | :--- | :--- |
| `primary` | Акцентные кнопки, индикаторы отправки, активные вкладки | Высококонтрастный пастельный тон |
| `primaryContainer` | Аватарки по умолчанию, бейджи непрочитанного, чипы | Мягкая заливка с высоким контрастом текста |
| `surface` | Фон экранов чатов, списков диалогов | В темной теме — глубокий AMOLED/графит |
| `surfaceVariant` | Поисковая строка-пилюля, входящие пузыри сообщений | Разделение слоев без жестких рамок |
| `onSurface` | Заголовки, имена собеседников, основной текст | 100% читаемость по WCAG AAA |
| `onSurfaceVariant` | Превью последнего сообщения, время отправки | Приглушенный вторичный тон |

## 2. Формы и геометрия (Soft & Round)

Yumigram использует выразительные радиусы скругления:
* **Кнопки и пилюли (Pill buttons)**: `24dp – 28dp` (полное скругление по краям).
* **Карточки диалогов**: `20dp`.
* **Пузыри сообщений (Chat Bubbles)**:
  * *Стиль по умолчанию (с хвостиком)*: `18dp` скругления + зауженный угол у стороны автора (`4dp`).
  * *Скругленный стиль*: `20dp` равномерного радиуса.
  * *Плоский стиль (Flat)*: минималистичные матовые плашки.

---

## 3. Физика жестов и взаимодействие

1. **Свайп по сообщению (Swipe-to-Reply)**:
   * Свайп влево на дистанцию от `80dp` активирует тактильный отклик (Haptic Feedback) и прикрепляет сообщение к плашке ответа над полем ввода.
2. **Свайп экрана (Swipe-to-Dismiss)**:
   * Горизонтальный свайп вправо из любой точки экрана чата на дистанцию от `150dp` плавно закрывает текущий диалог с интерполяцией прозрачности.
3. **Клавиатура (IME Padding)**:
   * Нижняя панель ввода и список сообщений синхронно поднимаются вместе с системной клавиатурой без рывков (`WindowInsets.ime`).

---

## 4. Индикаторы прочтения (Custom Indicators)

В настройках внешнего вида Yumigram доступен выбор стиля индикации:
1. **Точки (Default Pixel)**:
   * `•` — Сообщение отправлено на сервер (одна точка).
   * `••` — Сообщение прочитано собеседником (две точки).
   * *Особенность*: Индикатор отображается **только** на исходящих сообщениях пользователя!
2. **Галочки (Classic TG)**: `✓` / `✓✓`.
3. **Сердечки (Expressive)**: `♡` / `♥`.
4. **Слеши (Minimal Hacker)**: `/` / `//`.
